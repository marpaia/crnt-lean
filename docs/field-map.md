# Mathematical coverage map

This map records 99 advertised mathematical areas and the declarations that support them. `proved` means the stated result with the scope in the notes; `partial` means that only the listed components are proved. Hypotheses remain part of each result. The historical [semantic audit](semantic-audit.md) and [fix record](semantic-audit-fixes.md) explain the correspondence corrections. Compiling a module or checking axioms alone does not establish correspondence with its reference.

The inventory retains all named declarations from the audited map, updating names to describe their definitions. The export script checks every name and its axiom dependencies. Source references name mathematical targets; a partial row does not claim to formalize every result in its reference.
